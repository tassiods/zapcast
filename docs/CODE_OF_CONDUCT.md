# Code of Conduct

ZapCast adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is available at the link above and
applies in all project spaces (issues, pull requests, discussions, and any
other community channel associated with this repository).

## Summary

We pledge to make participation in this project a respectful,
welcoming, and constructive experience for everyone, regardless of
background or identity. In short:

- Be respectful and considerate in all interactions.
- Assume good faith; offer and accept constructive feedback.
- Focus on what is best for the project and the community.
- Keep discussions on-topic and free of personal attacks.

Behaviour that is disrespectful, demeaning, or otherwise inconsistent
with the Contributor Covenant is not acceptable in this project.

## Scope

This Code of Conduct applies within all project spaces and also when an
individual is officially representing the project in public spaces.

## Enforcement

Concerns about behaviour that may violate this Code of Conduct can be
reported privately to the maintainer through
[GitHub security advisories](https://github.com/tassiods/zapcast/security/advisories/new)
or by direct message on GitHub to **@tassiods**. All reports will be
reviewed and handled with discretion.

Maintainers are expected to follow and enforce this Code of Conduct in
good faith. Violations may result in actions ranging from a private
warning to a permanent ban from project spaces, at the maintainers'
discretion.
